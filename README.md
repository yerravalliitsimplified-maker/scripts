# Automation & Utility Scripts

A collection of Python and Shell scripts built to automate daily tasks, system administration, and data processing.

## Repository Structure

```text
scripts/
├── python/         # Python automation and data scripts (.py)
├── shell/          # Bash and Linux utility scripts (.sh)
└── README.md       # Project documentation
```

## Prerequisites

Make sure you have the following installed before running the scripts:
- **Linux / Bash** environment (for `.sh` scripts)
- **Python 3.8+** (for `.py` scripts)

## Usage

### Running Shell Scripts
1. Give the script executable permissions:
   ```bash
   chmod +x script_name.sh
   ```
2. Run the script:
   ```bash
   ./script_name.sh
   ```

### Running Python Scripts
1. Install any required packages (if applicable):
   ```bash
   pip install -r requirements.txt
   ```
2. Run the script:
   ```bash
   python3 script_name.py
   ```
